# Как самому управлять сайтом (студийный режим)

Студийный режим — это редактор прямо поверх сайта: добавляешь статьи и работы,
меняешь цены/шрифты/тексты, и публикуешь одной кнопкой. Кода не нужно.

## Два способа зайти

### 1. Локально (работает уже сейчас)
На этом ПК:
1. Запусти дев-сервер: в папке `D:\price` выполни `npm run dev` (или запусти
   существующий ярлык). Откроется `http://localhost:5173`.
2. Студия включена автоматически (localhost). Редактируй.
3. Кнопки внизу: **«Сохранить локально»** (записать в файлы без деплоя) и
   **«Опубликовать»** (закоммитить и выложить — сайт обновится через ~2 мин).

### 2. С любого браузера / телефона (после подключения VPS-эндпоинта)
1. Открой `https://vetor-studio.ru/?studio=1`.
2. Редактируй так же, как локально.
3. Жми **«Опубликовать»** → введи **ключ публикации** (студийный пароль) один раз
   за сессию → сайт обновится через ~2 мин.
   > Ключ спрашивается только для публикации. Без ключа посторонний может что-то
   > понажимать у себя в браузере, но выложить на сайт не сможет.

> Способ 2 заработает, когда на VPS-бэкенде появится эндпоинт публикации
> (см. `docs/backend-publish-endpoint.md`). Пока он не поднят — публикуй способом 1.

## Что можно делать

- **Статьи (блог).** Открой раздел «Блог» в студии → «Новая публикация».
  Собираешь пост блоками: текст (жирный/курсив/крупнее/цвет/ссылка/кнопка),
  фото, GIF, карусель, «до/после», таблица. Обложка, заголовок, описание, теги.
  Картинки автоматически ужимаются в webp.
- **Работы (Дизайн).** Content Studio → добавить/редактировать/удалить работу,
  загрузить файлы, задать категорию.
- **Профиль, разделы, цены, шрифты, тексты** — там же, через формы.

## Публикация = деплой

Кнопка «Опубликовать» пишет данные в исходники и пушит в GitHub → GitHub Actions
пересобирает сайт (~1–2 мин). Отдельно ничего запускать не надо.

## Важно

- **Сложные интерактивные штуки** (3-режимный лого-вьюер, встроенные превью
  сайтов, новые типы кейсов) — пока подключаются через код (мной). Обычный
  контент (статьи, цены, шрифты, тексты, простые работы) — полностью сам.
- Правки, сделанные в студии, до нажатия «Опубликовать»/«Сохранить» живут только
  в твоём браузере (localStorage). Не забывай публиковать.
